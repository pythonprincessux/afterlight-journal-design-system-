About this specimen

Afterlight Journal is an independent publication covering art, culture, design, place, and contemporary creative perspectives. This page is documentation for the publication's visual foundation — the tokens and reusable patterns later modules will build on for figures, forms, tables, and navigation. It is intentionally restrained: a specimen sheet, not a marketing homepage.

S1

Foundation + Reset

A small, selective reset — not a full browser strip. Each rule below exists for a specific reason; nothing is removed just because it's a common default. 

*,
*::before,
*::after {
  box-sizing: border-box;
}

body {
  margin: 0;
}

img,
svg {
  display: block;
  max-width: 100%;
}

button,
input,
select,
textarea {
  font: inherit;
}
Included, and why: box-sizing: border-box makes padding and border predictable in every width calculation. body { margin: 0 } removes the one universally unwanted default. img, svg sizing prevents media from overflowing narrow viewports. font: inherit on form controls stops inputs and buttons from silently falling back to the browser's UI font instead of Inter.

Intentionally not touched: focus outlines (enhanced via :focus-visible rather than removed — see S4), list markers, heading and paragraph margins, and native control affordances (checkboxes, radios, selects keep their recognizable browser-drawn appearance). These carry real semantic and usability value that a full reset would throw away for no system-level reason.

Control Foundations

Basic labeled controls that inherit the type system and share the same keyboard-focus treatment as links and buttons. Full form design is reserved for Module 3 — this is only the foundation.

Preferred edition
Labels are always real <label> elements tied to their control with for/id — placeholder text (as on Display name) is a hint, never a replacement for the label. Native checkbox, radio, and select rendering is kept rather than rebuilt, so browser and assistive-tech affordances stay intact. The primary button is reused directly from S4 rather than a new S6-only button style.

Documentation

Reset philosophy

Normalize only where there is a specific, named reason (box model, stray body margin, media overflow, form-control font inheritance). Leave every other browser default — focus rings, list markers, heading/paragraph spacing, native control rendering — in place, because they carry real usability value a blanket reset would erase for no system-level benefit.

Token hierarchy

Primitive tokens (e.g. --burgundy-600) describe a raw value. Semantic tokens (e.g. --color-action) describe its role. Components reference only semantic tokens, never a hex value or a primitive name directly. This is why the Midnight theme below only needs to remap eight semantic variables — not touch a single component rule.

Theme

Toggle the button at the top of the page to preview Midnight Editorial. It changes background, surface, text, muted text, border, action, action-hover, and focus — nothing else — because [data-theme="midnight"] only overrides semantic custom properties, never a component selector.
